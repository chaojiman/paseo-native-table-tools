Native table tools adds interactive controls to Paseo's native Markdown tables on desktop and web without replacing assistant replies or interfering with built-in workspace file links.

Instead of registering a timeline transformer that takes over reply rendering, the plugin attaches a lightweight client-side DOM overlay to rendered HTML tables and constrains long user message bubbles so pasted URLs and wide text wrap inside the chat column.

Paseo 0.17.4 or later is required. The overlay runs automatically on Paseo Desktop (macOS, Windows, and Linux) and in web browsers. Native iOS and Android apps treat the plugin as a safe no-op because native timelines render tables with native text views rather than HTML DOM elements. No accounts, tokens, settings, or daemon subprocesses are used.

Hover any Markdown table to copy it as GitHub Flavored Markdown or tab-separated values for spreadsheets, open it in a non-modal draggable and resizable floating window in either its original or transposed orientation, or toggle expanded width and full height. Click any column header to cycle ascending, descending, and original row order with unit-aware numeric comparison (`ms`, `s`, `Mbps`, `Gbps`, `KB`, `MB`, `GB`, ranges, and percentages). Drag a header's right edge to resize a column, and double-click or Alt-click a cell to copy its plain text. The plugin reads displayed table text in memory only when you sort, inspect, or copy, and never sends data over the network.
